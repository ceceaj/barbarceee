FASE 1: Masukin ke Gudang (GitHub)

Ada dua cara buat masukin kodingan lu ke GitHub. Pilih salah satu. Kalau mau santai, pakai Cara 1. Kalau mau kelihatan kayak Hacker depan gebetan, pakai Cara 2.

Paling Gampang

Cara 1: Jalur Santai (Drag & Drop via Web)

  1. Buka github.com dan Login (atau Sign Up kalau belum punya).
  2. Di pojok kiri atas, klik tombol hijau "New" buat bikin Gudang (Repository) baru.
  3. Isi kolom Repository name (Misal: web-pertama-gwe). Jangan pakai spasi!
  4. Pilih Public, lalu scroll ke bawah dan klik Create repository.
  5. Di layar selanjutnya, cari dan klik tulisan biru kecil: "uploading an existing file".
  6. Buka File Explorer di laptop lu. Blok semua isi folder project lu.
  7. Seret (Drag) semua file/folder itu dan Lepas (Drop) di kotak GitHub.
  8. Tunggu loading, lalu scroll ke bawah dan klik tombol hijau "Commit changes". Kodingan aman!

⚡ Cara 2: Jalur Suhu (Via Terminal VS Code)

Lakukan langkah 1-4 dari Cara 1 di atas, lalu Copy Link URL repository lu. Buka project di VS Code, pencet Ctrl + ~ buat buka Terminal. Ketik mantra ini satu per satu (tekan Enter per baris):

~ git init // Nyalain radar Git
git init
~ git add . // Bungkus semua file tanpa sisa
git add .
~ git commit -m "Upload karya pertama gwe"
git commit -m "Upload karya pertama gwe"
~ git branch -M main
git branch -M main
~ git remote add origin [LINK_GITHUB_YANG_LU_COPY]
~ git push -u origin main // 🚀 Peluncuran!
git push -u origin main

*Catatan: Kalau baru pertama kali, GitHub mungkin bakal minta lu login di popup yang muncul.

🚀

FASE 2: Publish ke Internet (Vercel)

Kodingan lu udah aman di GitHub, sekarang kita jadikan link website sungguhan!

  • 1
    Buka tab baru, masuk ke vercel.com dan klik Sign Up / Log In.
  • 2
    PENTING: Pilih tombol hitam "Continue with GitHub". Ini biar Vercel langsung dapet izin akses ke gudang GitHub lu tadi.
  • 3
    Di halaman Dashboard, klik tombol hitam "Add New" → "Project".
  • 4
    Nanti bakal muncul daftar repository dari GitHub lu. Cari nama folder yang baru lu bikin tadi (misal: web-pertama-gwe), lalu klik tombol "Import".
  • 5
    Di halaman Configure Project, nggak usah ada yang diganti. Langsung aja gas klik tombol gede: "Deploy".
  • 6
    Tunggu layarnya loading ngebangun web lu...
🎉

BOOM! Web Lu Mengudara!

Kalau keluar kertas warna-warni (Confetti), artinya sukses! Klik gambar preview webnya, atau klik Continue to Dashboard dan copy link URL lu (yang belakangnya .vercel.app).
