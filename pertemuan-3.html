1. Rahasia Tata Letak (Box Model)

Biar web lu nggak kelihatan kaku dan nempel di pojok layar terus, lu wajib paham anatomi kardus atau yang di CSS disebut Box Model. Semua elemen di HTML itu bentuknya kotak!

Visualisasi Margin & Padding

MARGIN (Jarak Luar)
BORDER / KARDUS
PADDING (Jarak Dalam)
Konten Web Lu
  • 📦
    Div (Kardus): Pembungkus elemen HTML biar gampang dipindahin barengan.
  • ↔️
    Margin: Jarak dari Luar kardus. Fungsinya dorong tetangga biar ngejauh.
  • 🛡️
    Padding: Jarak dari Dalam kardus. Ibarat bubble wrap biar isi kardusnya aman dan nggak nabrak dinding.

2. Tulang Form (index.html)

Bikin file index.html dan masukin kode ini. Perhatiin tag <link rel="stylesheet" href="style.css"> di atas, itu kabel wajib buat nyambungin HTML ke CSS lu.

index.html 

<!DOCTYPE html>
<html lang="id">
<head>
    <title>Login BARBARCC</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="kardus-login">
        <h2>Login Tongkrongan</h2>
        <form>
            <label>Nama Lu:</label><br>
            <input type="text" class="input-teks" placeholder="Ketik nama..."><br>

            <label>Password:</label><br>
            <input type="password" class="input-teks" placeholder="Ssst..."><br>

            <button type="button" class="tombol-gas">Masuk Coy!</button>
        </form>
    </div>
</body>
</html>

3. Baju Form (style.css)

Bikin file style.css di folder yang sama, lalu paste kode ini. Coba buka Live Server dan lihat form lu disihir pindah ke tengah layar!

style.css 

body {
    background-color: #e0e6ed;
    text-align: center;
    font-family: sans-serif;
}

.kardus-login {
    background-color: white;
    width: 300px;
    margin: 50px auto; /* Ajaib: bikin form ke tengah horizontal */
    padding: 30px;
    border-radius: 15px;
    box-shadow: 0px 10px 20px rgba(0,0,0,0.1);
}

.input-teks {
    width: 90%;
    padding: 10px;
    margin-bottom: 15px;
    border: 1px solid #ccc;
    border-radius: 5px;
}

.tombol-gas {
    background-color: #3b82f6;
    color: white;
    padding: 12px 20px;
    width: 100%;
    border: none;
    border-radius: 5px;
    font-weight: bold;
    cursor: pointer;
    transition: 0.3s;
}

🔥 Mini Challenge!

Bosen sama warna biru form loginnya? Selesaikan tantangan ini sebelum lu pulang:

Tugas 1: Ganti Cat

Ubah background-color tombolnya jadi warna kesukaan lu (contoh: crimson, teal, atau orange).

Tugas 2: Sensor Sentuh (Hover)

Bikin tombolnya berubah warna pas kena mouse! Ketik di paling bawah file CSS lu:

.tombol-gas:hover { background-color: black; }
